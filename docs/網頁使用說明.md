# 網頁使用說明

本頁說明選型網頁的每個功能。網頁全部以點選操作，不需要輸入文字。

標題下方顯示目前的機種筆數與資料庫日期（台灣時間），日期是資料最後一次更新的時間，可以用來確認看到的是不是最新資料。

## 開啟方式

| 方式 | 做法 | 適合 |
|---|---|---|
| 線上網址 | 開啟 GitHub Pages 網址，例如 `https://<帳號>.github.io/<儲存庫名稱>/` | 業務分享給同事或客戶 |
| 本機離線 | 下載整個資料夾，雙擊 `index.html` | 沒有網路的現場 |

離線開啟時，字型會改用電腦內建字型，其他功能完全相同。

右上角的「字級」可切換標準、大、特大三種字體大小，網頁會記住您的選擇。

頁面上方有五個分頁，網址最後的 `#find`、`#model`、`#replace`、`#compare`、`#about` 分別對應各分頁，可以直接把網址傳給別人，對方會開在同一個分頁。

## 一、找機種

依需求條件篩選，點選條件後結果即時更新。

1. **電腦**：條件欄固定在左側，可獨立捲動，捲動結果時條件一直看得到。
2. **手機與平板**：結果直接顯示在畫面上，按上方橘色的「篩選條件　點此設定」按鈕打開全螢幕條件面板，選好後按底部的「看結果（N 款）」回到結果。按鈕上會顯示已選幾項。

除了記憶體以外，所有條件都可以複選：同一區塊選多項代表「符合其中一項即可」，不同區塊則要同時符合，不選代表不限。條件分成幾個可收合的區塊，標題旁的數字是這個區塊已選幾項。區塊順序依選型習慣排列：系列、開發軟體、螢幕尺寸、開口尺寸、遠端與網路功能、介面、記憶體、觸控、傳輸線、停售狀態。前五項預設展開，其餘預設收合，展開或收合的狀態會被記住。

### 條件說明

| 條件 | 說明 |
|---|---|
| 系列 | 依等級分組（進階、標準、基本、入門、舊機種、工業電腦）。不選代表全部系列，可複選 |
| 開發軟體 | 分成 GP-Pro EX 版本與其他開發軟體。不選時，所有機種全部列出，包含 GP3000、GP-4402WW 等新版已不能新建的機種。選「4.09 可開發」之類的版本，只列出該版本可以新建專案的機種，適合確認客戶手上的軟體能不能用；「BLUE 可開發」「BOS 可開發」（BLUE Open Studio）依原廠支援機種頁，只列出目前版本可用的機種；「PB III 舊硬體」只列出要用 GP-PRO/PB III 開發的舊機。選多項代表任一項可開發即可 |
| 螢幕尺寸 | 可複選，例如同時選 5.7 吋和 7 吋 |
| 畫面比例 | 在螢幕尺寸區塊內，可選寬螢幕、4:3，依解析度判斷 |
| 開口尺寸 | 可以點上方的「開孔板」圖，也可以點下方的尺寸按鈕。圖是依實際比例畫的，越大的開口框越大。每個尺寸按鈕後面的小字是使用這個開口的螢幕尺寸。可同時選多個開口 |
| 需要的功能 | 可複選，必須「支援」才算符合。「有條件」的機種會列入結果，但卡片上會提醒 |
| 介面 | LAN 埠數、RS-232C、RS-422/485、USB A、SD／CF 卡槽 |
| 記憶體 | 使用者資料記憶體（8、16、32、64、128 MB 以上）與備份記憶體（128 KB、320 KB、5 MB 以上）。每組只能選一項，代表「至少」需要這個容量。以 GP-Pro EX 的 XML 數值比對，不含可擴充的容量。容量不足的機種會列在接近機種，並寫出少多少 |
| 觸控 | 類比電阻、多點觸控、投射電容、矩陣 |
| 傳輸線 | 選手上有的線，列出能用這條線傳畫面的機種：USB A 對 mini-B、USB A 對 micro-B、USB A 對 USB A 專用線（CA3-USBCB-01）、圓形 Tool 連接埠（GP2000） |

機種詳細頁的規格表會列出傳輸線與開發軟體。一般 USB 線只寫接頭型式；原廠專用線（CA3-USBCB-01、GP2000 的 GPW-CB02、GPW-CB03、GPW-CB-SET）才寫型號。「說明與來源」分頁列出 CA3-USBCB-01 支援的系列。

GP2000 系列（含更早的 GP-37W2、GP-470、GP-570）GP-Pro EX 不支援，不顯示 GP-Pro EX 版本標籤，改顯示紫色「PB III 舊硬體」，開發軟體為 GP-PRO/PB III。找機種的「開發軟體」條件也可以選「PB III 舊硬體」，只列出這些舊機。舊機替換時可選 GP2000，會列出原廠建議替換（含停售、停修日期）、「舊專案轉到 GP-Pro EX」可轉換的機種，以及開口相同或相近的現行機種。

條件會自動記在瀏覽器裡，下次開啟時保留。

結果上方會列出所有已選條件，點任一個就能移除那個條件，點「全部清除」重新開始。也可以按結果右上角、條件欄最上方的「重新選擇」（手機在上方篩選條件按鈕旁），一次清除所有條件與排序。已停產且完全沒有遠端與網路功能的舊機，卡片不顯示功能標籤，詳細頁仍會列出。已停售的機種卡片會顯示紅色「已停售 日期」，可用「停售狀態」條件排除。結果可以切換排序：依系列、尺寸小到大、尺寸大到小。

### 結果說明

1. **符合條件**：所有條件都符合的機種。
2. **接近機種（差 1～2 項）**：只差一兩項的機種，虛線外框，黃色框寫明差在哪裡，例如「差異：開口 190×135」。尺寸、開口越接近的排越前面。
3. **SP5000** 的顯示器和 Box 會合併成一張卡片，「可搭配 Box」列出符合條件的 Box。
4. 卡片上方逐一標示每個 GP-Pro EX 版本的狀態，例如 GP-4402WW 會顯示「4.08 ✓　4.09 ✓　5.01 僅開啟　5.02 僅開啟」。綠色 ✓ 可新建、藍色「✓ 免費版」免費版可用、黃色「僅開啟」只能開啟舊專案、灰色虛框「待確認」該版 XML 把機種名稱寫成代稱（例如 5.02 的 GP-4301TW 寫成 F5.7B），狀態尚未確認、灰色「未收錄」該版本沒有這台機種。可用 BLUE 開發的機種另標藍色「BLUE ✓」（只有舊版 BLUE 支援時標黃色「BLUE 舊版」），可用 BLUE Open Studio 的標「BOS ✓」。
5. 卡片中的功能標籤：✓ 支援、✗ 不支援、△ 有條件、舊版才有或待確認。

手機上條件區在上方，選完條件後按「看結果」會跳到結果區。

## 二、查機種

已經知道型號時使用。

1. 點選系列，系列依等級分組。
2. 點選子系列，例如 GP-41** Series、GP-45** Series，分法與 GP-Pro EX 新建專案時相同。預設「全部」，按鈕旁的數字是機種數。系列內只有一組時不顯示這一步。
3. 點選機種。各版本 GP-Pro EX 能否新建，在詳細頁的規格表列出。
4. 如果是 SP5000，選顯示器後再選 Box（SP5000 沒有子系列這一步）。
5. 選好後畫面會自動捲到詳細資料。
6. 要換查別台，直接點其他系列或機種；想全部清掉，按右上角的「重新選擇」。

詳細頁的內容：

| 區塊 | 內容 |
|---|---|
| 遠端與網路功能 | 每個功能的支援狀態、Remote HMI 連線數、最低 GP-Pro EX 版本與備註 |
| 開口尺寸 | 寬 × 高、面板厚度，附比例圖。資料需再確認時會標示 |
| 原廠建議替換 | 原廠替換手冊列出的建議機種，並註明開口是否相同，附手冊連結 |
| 特殊開關切換 | 只有內部版會顯示。列出這台機種專屬的特殊開關，和功能有關的開關也會寫在功能表的備註欄，通用開關列在「說明與來源」分頁。公開網站沒有這個區塊 |
| 規格 | LAN、COM、USB、記憶卡槽、使用者資料記憶體、備份記憶體、首次出現的 XML 版本等。記憶體以 XML 為主，後面註明原廠規格頁的容量（不同時標「與 XML 不同」），原廠頁另外寫的快閃記憶體、裝置記憶體等放在「原廠規格頁記憶體說明」，資料來源列出該原廠規格頁 |
| 開口相同的現行機種 | 點下去直接跳到該機種 |
| 資料來源 | 這台機種每項資料的原廠出處 |

右上角「原廠系列頁」會開啟 proface.com 的英文產品頁。

## 三、舊機替換

客戶現場要換機時使用。

1. 選舊機的系列，例如 GP3000。所有系列、所有機種都可以選。
2. 選子系列（可略過，預設全部），再選舊機型號。
3. 頁面會列出：
   1. **原廠建議替換**：來自原廠替換手冊與停售頁，附連結；上方列出舊機的停售與停修日期。
   2. **開口相同、可直接換裝的現行機種**：每張卡片會寫出「比舊機少」哪些功能，例如少了 GP-Viewer EX 或少了 RS-232C；功能沒有減少時顯示「功能不少於舊機」。開口相同的機種中，同時是原廠建議替換的會標綠色「原廠建議」並排在最前面；已停售的機種標紅色「已停售」並排在後面。
   3. **沒有開口相同的機種時**：頁面會先標示「沒有開口相同規格的現行機種，以下只是開口尺寸相近的機種，不是同規格」，再分兩類列出：
      1. **擴孔即可（新機開口較大）**：在原孔上往外切即可。
      2. **需轉接板或補板（新機開口較小）**：舊孔太大，需要補板或轉接板。
      每張卡片寫出新機開口與舊機的差，例如「寬 +7.5、高 +11.5 mm」。每類最多 3 款，同一系列只列最接近的一款，差距超過 30 mm 不列。這只是依開口尺寸推算，不是原廠建議，施工前請確認新機外框、盤內深度與原廠外形圖。
   4. 手持型、工業電腦、盒型主機與後模組不是面板開孔安裝，頁面會直接說明不比對開口。
4. 按「與舊機比較」會把舊機和新機一起放到比較頁。
5. 按右上角的「重新選擇」清除所有選擇。

## 四、比較

1. 在任何頁面按「加入比較」，最多 4 台，超過時最早加入的會被移出。
2. 有機種在比較清單時，畫面下方會出現比較列，按「開始比較」。
3. 比較表中，各機種不同的項目會用底色標出。
4. 比較清單也會記在瀏覽器裡。
5. 按「列印／存成 PDF」會開啟瀏覽器的列印視窗，只印出比較表（A4 橫式，含列印日期與資料庫日期）。印表機選「另存為 PDF」即可存檔寄給客戶。

## 五、說明與來源

列出各功能的說明、狀態標示的意義、資料版本與資料庫日期，以及所有原廠資料來源連結。內部版另有完整的特殊開關切換表。

## 狀態標示

| 標示 | 意義 |
|---|---|
| 支援 | 原廠文件明確支援 |
| 不支援 | 原廠文件明確不支援 |
| 有條件 | 需符合特定條件，例如需另購授權、需 LAN 埠或限特定 Box，詳見備註 |
| 舊版才有 | 只有較舊的 GP-Pro EX 支援，例如 Web Server 只到 4.09.450 |
| 待確認 | 尚未找到原廠明確資料 |
| 版本 ✓ | 該版 GP-Pro EX 可以新建專案 |
| 版本 ✓ 免費版 | 該版 GP-Pro EX 免費版即可開發 |
| 版本 僅開啟 | 該版可以開啟舊專案，但不能新建 |
| 版本 未收錄 | 該版 GP-Pro EX 沒有這台機種 |
| PB III 舊硬體 | 只用於舊硬體（例如 GP2000 系列），GP-Pro EX 各版本都不支援，開發軟體為 GP-PRO/PB III |
| LAN 埠、USB A「無」 | 這台機種沒有該介面（資料為 0）；「未標示」表示資料來源沒有寫 |

版本狀態依各版 GP-Pro EX 的 HmiInfo.xml 判斷。4.08、4.09 的 XML 收錄的機種都視為可新建；5.01、5.02 依 XML 的 supported 標記區分。5.02 的 XML 有 5 台機種（GP-4301TW、GP-4501TW、GP-4301TM 模組型、ST-6300TA、ST-6500TA）名稱寫成 F5.7A 這類代稱，網站沿用原本的名稱，5.02 狀態標「待確認」，詳細頁的「XML 名稱變更」列出代稱。

詳細頁的「其他 COM 埠」：5.02 的 XML 為部分機種多列了 COM 埠。GP6000 Advanced 的 COM3、COM4 來自序列介面擴充單元 PFXZHMUSIO1，本體只有 COM1、COM2；SP-5B40、SP-5B41 另列 COM3～COM9，原廠文件未說明來源。COM 埠欄與找機種的介面條件只算本體內建的埠。

## 注意事項

本工具為初步選型。正式採購、改孔或替換前，請依確切型號、硬體版本、GP-Pro EX 版本與原廠最新文件確認。

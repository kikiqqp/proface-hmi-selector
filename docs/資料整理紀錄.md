# 資料整理紀錄

記錄這份資料怎麼來的、做過哪些判斷，以及還沒確認的地方。修改資料前請先讀完，避免把已經查證過的值改錯。

整理日期：2026 年 11 月。

## 一、XML 來源與結構

| 檔案 | 來源 | 系列數 | 機種數 |
|---|---|---|---|
| `xml/HmiInfo_4.08.xml` | GP-Pro EX 4.08 | 9 | 145 |
| `xml/HmiInfo_4.09.xml` | GP-Pro EX 4.09 | 11 | 172 |
| `xml/HmiInfo_5.01.xml` | GP-Pro EX 5.01 | 18 | 204 |

結構重點：

1. `Series` 底下是 `Model`，`Model` 底下是一或多個 `Revision`，`Revision` 底下是 `Property`。
2. **第一個 Revision 是完整資料，之後的 Revision 只記錄差異**。例如 AGP-3300L 的第二個 Revision 名稱為 `Rev*-4>=`，只有 `MemoryEnlargement=yes` 等 4 個欄位。
3. `Model` 的 `id` 在各版本間穩定，但 GP3000 有同 id 不同名稱的變體（例如 `-CA1M`），所以用 `id + 群組 + 名稱` 當唯一鍵。
4. 5.01 的 `Model` 多了 `supported` 屬性：
   1. 空白：可新建。
   2. `free`：GP-Pro EX 5.x 免費版可用（原廠公告為 ET6000 與 GP-4100 彩色機，XML 另標了 ET5000）。
   3. `no`：可開啟舊專案，但不能新建。

   4.08、4.09 的 XML 沒有這個屬性，收錄的機種一律視為可新建。網站把三個版本取聯集全部列出，每台機種記錄各版本狀態（`versions`），沒收錄的版本標「未收錄」。例如 GP-4402WW：4.08 可新建、4.09 可新建、5.01 僅可開啟。
5. 4.09 曾移除 GC4000 與 ST3000W，5.01 又加回來並標為 `no`。
6. SP5000 在 XML 是「顯示器 × Box」的組合，每個組合一筆，`size` 屬性是 Box 型號。
7. 部分機種名稱帶有解析度尾巴，例如 `ST-6300TA VGA (640*480)`，網頁顯示時會去掉。
8. 解析度只有代碼。`MQVGA`（200×80）與 `WXGAV`（800×1280 直式）兩個代碼另外查原廠規格補上，對照表在 `tools/xml2models.py` 的 `RES`。
9. 5.01 的 XML 已含 GP6000 Advanced 與 GPH6000，原廠更新說明寫這兩個系列是 5.01.000 才支援，所以這份 XML 確認是 5.01 版。

XML 的 `WebServer`、`RemoteHMIMaxConnection` 等欄位代表**硬體能力**，不代表目前軟體版本實際可用，詳見下一節。

## 二、功能支援的判斷原則

1. **以 XML 資料為主，但需要二次查核**。查核依據為原廠文件或現場實機確認，查核結果寫在 `data/csv/features.csv`。有查核結論時以查核結論為準；查不到時採用 XML：XML 標有為支援，標無或沒有此欄位為不支援。規則寫在 `tools/build.py` 的 `XML_FALLBACK`，適用 Remote HMI（連線數一併帶入）、FTP、E-mail、EZ LAN、Web Server。
2. 二次查核的來源，**以 GP-Pro EX 線上手冊「1.5 支援功能」表為主**，網址格式為 `https://www.proface.com/data/manual/gpproex/new/refer/mergedProjects/welcome/welcome_mm_<系列>.htm`，例如 `welcome_mm_gp4500.htm`、`welcome_mm_st6000.htm`。
3. 手冊沒有的系列，用原廠產品頁、授權頁、更新說明查核。查不到又沒有 XML 欄位的功能（GP-Viewer EX、Pro-face Connect、IPsec）才標「待確認」。
4. Remote HMI 的連線數與最低版本，以 Remote HMI Client for Win 規格頁查核。
5. Web Server 只支援到 GP-Pro EX 4.09.450，所以 XML 標有的機種判定為「舊版才有」。
6. 備註不寫「XML 標示有」這類說明，依據列在「資料來源」（代號 S_XML）。
7. 原廠 Otasuke 網站（`pro-face.com/otasuke`）目前只顯示暫停服務公告，內容已移到 `proface.com/en`，所有連結都改用 proface.com。

### 重要發現

| 項目 | 內容 | 影響 |
|---|---|---|
| Web Server | 手冊註明只支援到 GP-Pro EX 4.09.450，之後版本全系列不可用；XML 仍有很多機種標 yes | 現行機種一律標「舊版」或「不支援」 |
| GP6000 Standard | 手冊標示 GP-Viewer EX、E-mail 不支援 | 從 GP3000 換過來的客戶要特別說明 |
| ET6000 | Pro-face Connect 不支援 | |
| GP6000 Advanced Remote HMI | Client for Win 頁寫 5 台，XML 寫 3 台 | 暫採 5 台，備註標示衝突 |
| SP5000 Open Box GP-Viewer EX | 手冊功能表列支援，授權設定頁排除 Open Box | 現場確認支援，標「支援」 |
| GP-Viewer EX 授權 | 每台人機一組 EX-VIEWER-LICENSE，一組最多 3 個同時連線 | |
| Pro-face Remote HMI Server | 5.0 起停止支援（手機 App 不受影響） | |
| GP4000M、GP-4201TW、GP4100 | Pro-face Connect 原廠清單排除 | |

### 查核結果與 XML 不一致的地方（以查核結果為準）

| 項目 | XML | 查核結果 | 說明 |
|---|---|---|---|
| GPH6000 Remote HMI | 連線數 3 | 不支援 | 現場確認 |
| GP-4402WW、GP-4502WW Remote HMI | 無 | 有條件 | 現場確認，需開啟特殊開關切換 |

| GP6000 Advanced Remote HMI 連線數 | 3 | 5 | 原廠 Client for Win 規格頁，尚待確認 |

### 現場實機確認（2026-11，來源代號 S_FIELD）

| 機種 | GP-Viewer EX | Remote HMI |
|---|---|---|
| GP-4402WW、GP-4502WW | 支援 | 有條件：需開啟特殊開關切換 |
| GP-4311HT、GP-4G01、GP-4501TTF、GP-4601TTF | 支援 | 支援 |
| SP5000 Open Box（SP-5B40、SP-5B41） | 支援 | 支援 |

| GPH6000 | 不支援 | 不支援 |
| ET5000 | 支援 | 支援 |

ET5000 另確認 Pro-face Connect、IPsec 不支援。

一般規則：Remote HMI 不支援的機種，通常 GP-Viewer EX 也不支援。例外是 GP3000、LT3000 這類在 Remote HMI 推出前的機種，原廠 GP-Viewer EX 頁面列為支援。

## 三、開口尺寸

1. 只採用原廠手冊、規格頁或型錄的明確數值，不用螢幕吋數推算。
2. 同吋數不一定同開口，例如 GP-4501TW（10.4 吋 W 型）與 ST-6500TA（10.4 吋）都用 12.1 吋外框 301.5×227.5；GP3000 的 10.4 吋 STN 機種也是 301.5×227.5，TFT 機種則是 259×201。
3. `需再確認 = Y` 的資料：
   1. GP-4104～4107：105×66 是由 GP-4114T 轉接框說明推定。
   2. GC4000：來源是第三方網站轉載的原廠安裝指南。
4. 尚未查到：LT-4201TM／4301TM 的圓孔孔徑（GP-4201TM／4301TM 已依原廠 GP4000M 系列頁確認為 φ22，STM6000 已確認為 φ22.5）、GP-4501TTF／4601TTF、SP5000X 戶外型顯示器、ST3000W、HTK3300V、LT-3201A。

## 五、待確認事項

以下需要原廠窗口或實機確認，確認後請改 CSV 並更新本節：

1. GP6000 Advanced Remote HMI 連線數是 3 還是 5。
2. GP6000 Standard 是否真的不支援 GP-Viewer EX 與 E-mail。
3. GP6000 Advanced、GPH6000、STC6000 除了 GP-Viewer EX 與 Remote HMI 以外的功能（未找到手冊 1.5 頁面）。
4. GP-4G01、GP-4311HT、GP-4501TTF、GP-4601TTF 除了 GP-Viewer EX 與 Remote HMI 以外的功能、開口，以及 TTF 的意義。
5. GP-4402WW、GP-4502WW 開啟 Remote HMI 所用的特殊開關編號。
6. 模組型人機的圓孔孔徑。
7. XML 標為 `supported=no` 但不在原廠停止支援公告的機種：GC4000、ST3000W、HTK、GP4000M、GP-4402WW／4502WW、GP-4G01（依使用者說明，暫視為可開啟、不可新建）。
8. ET5000 是否可用免費版（XML 標 free，原廠 Free 清單未列）。
